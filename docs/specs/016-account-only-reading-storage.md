# 016-account-only-reading-storage: 사주 결과 계정 저장만 제공

## 목적과 결정

로그인이 필수인 현재 서비스에서는 해석 결과를 브라우저와 계정에 이중 보관하지 않습니다. 사용자가 직접 `현재 결과를 계정에 저장`을 누른 결과만 계정 데이터베이스에 보관합니다. 저장하지 않은 새 해석은 현재 화면에서만 볼 수 있고, 새로고침하거나 화면을 떠나면 복원되지 않습니다.

## 화면과 동작

1. `사주 보기`에서 기본·주제 해석을 생성하면 현재 화면에 표시합니다. 생성 성공만으로 브라우저 또는 계정에 자동 저장하지 않습니다.
2. 계정 저장 영역에서 선택형 별칭을 정하고 현재 결과를 저장할 수 있습니다. 계정에 저장한 목록의 열기·삭제·더 보기는 유지합니다.
3. 이미 계정에 저장한 결과에서 새 주제 해석을 만들면 그 결과를 기존 계정 행에 갱신합니다. 신규 결과는 명시적 저장 전까지 계정 행을 만들지 않습니다.
4. `이 브라우저에 저장`·`지난 해석 다시 보기` 목록, 브라우저 저장 오류 안내, 브라우저 결과 열기·삭제 동작을 제거합니다. 계정 삭제 문구에도 별도의 브라우저 결과를 언급하지 않습니다.
5. 과거 버전이 브라우저 `localStorage`에 남긴 결과를 읽거나 쓰거나 자동 이관하지 않습니다. 이번 변경이 기존 브라우저 저장값을 실제로 지우지는 않습니다. 옛 결과는 새 화면에서 접근할 수 없으며, 실제 삭제 또는 이관은 별도 사용자 결정이 필요합니다.

## 완료 조건

- 앱 코드에서 사주 결과용 `localStorage` 읽기·쓰기와 관련 화면·버튼이 없습니다.
- 기본·주제 해석은 계정 저장 없이 화면에 표시되고, 수동 계정 저장 후 재열람할 수 있습니다.
- 계정 저장 결과의 열기·삭제·더 보기와 기존 결과의 주제 해석 갱신이 유지됩니다.
- 기존 브라우저 데이터는 자동 삭제·이관되지 않습니다.

## 검증 기록

- 2026-09-29: 독립 테스트 담당자가 브라우저 저장 관련 옛 검사를 제거하고 계정 단일 저장 회귀 검사를 보강했습니다. 관련 42건, 전체 `npm run check` 111건, `npm run build`, `git diff --check`가 통과했습니다.
- 실제 로그인한 브라우저에서 새 결과 생성 → 계정 저장 → 새로고침 후 재열람 → 삭제 순서를 아직 확인하지 않았습니다. 이 확인 전까지 `docs/status.md`는 미완료로 둡니다.
