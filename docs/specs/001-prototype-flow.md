# 001-prototype-flow: 입력부터 관심 주제 선택까지

## 목표

사용자가 생년월일과 출생시간을 입력해 기존 계산 결과를 확인하고, 다음 단계에서 관심 주제 하나를 선택하는 화면 흐름을 직접 사용해 봅니다.

## 범위

- 양력 생년월일과 출생시간 입력, 기존 `lib/saju` 계산 및 오류 안내를 유지합니다.
- 계산 결과에는 네 기둥과 계산 기준 등 사실 기반 결과만 표시합니다. 운세나 성향 해석을 생성하지 않습니다.
- 결과를 확인한 뒤 `성격·강점`, `연애·관계`, `일·진로`, `재물` 중 하나를 선택할 수 있습니다.
- 선택한 주제는 화면에서 구분되며, 해당 영역은 `해석 준비 중`으로 명확히 표시합니다.
- 사용자가 입력을 바꿔 다시 계산하면 이전 주제 선택은 초기화합니다.
- 좁은 화면에서도 입력, 결과, 주제 선택을 순서대로 사용할 수 있습니다.

## 이번에 만들지 않는 것

- 사주 해석 문구, AI 호출, 자유 질문, 로그인, 결과 저장, 결제, 공유.

## 확인 방법

1. 유효한 날짜와 시간을 입력하면 기존 계산 결과가 표시됩니다.
2. 주제 버튼을 누르면 해당 버튼의 선택 상태와 준비 중 영역의 주제명이 바뀝니다. 해석처럼 보이는 문장은 표시하지 않습니다.
3. 유효하지 않은 값을 넣으면 안내가 표시되고 이전 결과와 주제 선택이 사라집니다.
4. 날짜나 시간을 바꿔 다시 계산하면 이전 주제 선택이 사라집니다.
5. 형식 검사, 자동 검사, 실제 브라우저 화면을 확인합니다.
