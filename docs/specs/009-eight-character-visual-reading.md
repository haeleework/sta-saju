# 009-eight-character-visual-reading: 8글자 색상 도표와 오행 분포 풀이

상태: 코드·자동 검사 완료 · 로그인한 실제 화면 확인 전

작성일: 2026-09-23

## 목표

사주를 처음 보는 사람도 8글자의 위치와 각 글자의 오행을 한눈에 읽고, 숫자를 넘어 나를 대표하는 글자(일간)와 주변 기운의 관계를 이해하게 합니다.

## 화면

1. `나의 사주 구성`에서 년·월·일·시를 네 열로, 윗글자(천간)·아랫글자(지지)를 두 행으로 배치하여 정확히 2×4=8칸을 보여줍니다. 각 칸에 한자 한 글자, 대응하는 한글 한 글자, 오행 이름을 표시합니다. 한자와 한글은 기존 만세력 계산 결과에서 얻습니다.
2. 각 칸의 배경·테두리를 목·화·토·금·수별로 구분합니다. 색에만 의존하지 않도록 오행 이름을 함께 표기합니다. 작은 화면에서도 네 열과 여덟 칸의 관계를 유지합니다.
3. 바로 아래에 목·화·토·금·수 순서의 가로막대 다섯 개를 보여줍니다. 각 막대는 8글자 중 해당 오행의 개수(0~8)를 뜻하며, 0개도 표기합니다. 숫자 합계는 8입니다. 이는 천간 4개와 지지의 대표 오행 4개만 센 값이며 지장간·계절 가중치는 포함하지 않습니다.
4. 그래프 바로 아래에 일간을 기준으로 두드러지는 오행이 어떤 관계인지 쉬운 문장으로 풉니다. 가장 많이 보이는 오행이 여러 개면 함께 다룹니다. 계절·뿌리의 도움과 다른 글자의 작용을 함께 설명하되, 강약의 `판단 보류`를 전체 풀이의 결론처럼 내놓지 않습니다. 개수만으로 성격·미래를 확정하지 않습니다.
5. 세부 계산 근거는 펼쳐 볼 수 있는 영역으로 내려서, 처음 보는 화면은 8글자와 분포·풀이가 중심이 되게 합니다. 기존 Gemini 기본 해석 버튼과 주제별 해석, 로그인 제한, 저장 결과 재열람은 유지합니다.

## 비용과 데이터

- 그래프와 바로 아래 짧은 풀이는 기존 계산 결과로 브라우저에서 만듭니다. Gemini 자동 호출을 추가하지 않습니다. 더 자세한 전체 해석은 기존 `해석 만들기` 버튼을 눌렀을 때만 생성합니다.
- 기존 저장 결과 형식과 API 요청·응답을 변경하지 않습니다. 저장한 과거 결과도 같은 도표·그래프·짧은 풀이로 다시 보여줍니다.

## 검증

- 글자 순서, 한자·한글·오행 대응, 다섯 막대와 합계, 동률·0개 분포, 해석 문장을 자동 검사합니다.
- 로그인 전 접근 제한과 해석 API 호출 정책을 회귀 검사합니다.
- 형식 검사, 전체 테스트, 배포용 빌드를 실행하고 실제 로그인 화면은 별도로 확인합니다.
