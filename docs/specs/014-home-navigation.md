# 014-home-navigation: 상단 브랜드와 홈 이동

상태: 코드·자동 검사 완료 · 실제 로그인 화면 검증 전

작성일: 2026-09-29

## 목표

- 로그인 후 `오늘의 운세 보기`나 `사주 보기` 화면에서 상단 `나의 결`을 누르면 두 서비스를 고르는 홈으로 돌아갑니다.
- 기존 `← 선택 화면` 버튼은 목적이 분명한 `← 홈으로`로 표시하고, 같은 홈 이동 동작을 유지합니다.
- 홈 이동은 로그아웃이나 새 Gemini 요청을 만들지 않습니다. 비로그인 상태의 브랜드는 이동 버튼으로 표시하지 않습니다.

## 이번 범위와 별도 점검

- 브라우저의 뒤로가기는 현재 서비스 선택 상태가 주소·방문 기록에 기록되지 않아 홈을 거치지 않을 수 있습니다. Google 계정 선택 화면으로 돌아가는 현상은 로그인 과정이 외부 페이지를 거치는 점과 함께 별도로 점검합니다.
- 이번 변경은 명시적인 홈 이동 두 곳에 한정합니다. 브라우저 방문 기록, 로그인 뒤 주소 처리, 비로그인 랜딩 흐름 변경은 이 Spec에서 하지 않습니다.
- 계정 저장 결과의 원본 생년월일시·성별 보관 정책도 변경하지 않습니다. 기존 `004`, `013`의 결정이 유지됩니다.

## 확인 방법

1. 로그인 상태에서 홈의 두 선택지를 확인하고, 각각의 화면에서 `나의 결`과 `← 홈으로`를 눌러 홈으로 돌아오는지 확인합니다.
2. 비로그인 상태에서 사주·운세 화면이 숨겨지고 기존 로그인 안내가 보이는지 확인합니다.
3. `npm run check`, `npm run build`를 실행하고 기존 계산·해석·운세 검사가 통과하는지 확인합니다.

## 검증 기록

- 독립 담당자가 상단 브랜드 버튼, 비로그인 시 비노출, 두 서비스 화면의 `← 홈으로`, 단일 홈 상태 연결을 검사한 테스트 3건을 추가했고 모두 통과했습니다.
- 전체 `npm run check` 103건과 `npm run build`가 통과했습니다. 기존 사주 계산·해석·계정 저장·오늘 운세 자동 검사를 포함합니다.
- 실제 로그인 브라우저의 클릭 동작과 뒤로가기 순서는 아직 확인하지 않았습니다.
