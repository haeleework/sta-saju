# 007-account-header: 계정 정보의 최상단 배치

상태: 코드·자동 검사 완료 · 실제 로그인 화면 확인 전

작성일: 2026-09-23

## 목표

로그인한 사용자의 계정 정보와 로그아웃 버튼을 화면 최상단에 모으고, 사주 입력·결과 흐름 사이의 로그인 상태 카드는 제거해 가독성을 높입니다. 사용자 식별자는 별도 내부 UUID 대신 사용자가 알아보기 쉬운 구글 계정 이메일로 표시합니다.

## 동작

- 최상단 브랜드 오른쪽에 로그인한 이메일과 로그아웃 버튼을 표시합니다. 좁은 화면에서도 줄바꿈하거나 간결하게 표시해 버튼이 가려지지 않게 합니다.
- 로그인 상태 확인 중에는 계정 이메일을 추측해 보여주지 않습니다. 비로그인 상태에서는 기존 로그인 안내와 Google 로그인 버튼을 사주 입력 전 별도 영역에 유지합니다.
- 로그인한 뒤에는 사주 흐름 위에 `구글 로그인 시험`, `로그인됨` 같은 별도 카드를 두지 않습니다. 로그인 시험 모드의 비용 차단 안내는 계정 카드가 아닌 사주 기능 안내와 화면 하단에 남깁니다.
- 로그아웃하면 계정 정보와 사주 화면을 즉시 숨기고 기존 로그인 안내를 표시합니다. 해석 API의 인증·비용 제한은 변경하지 않습니다.

## 완료 조건

1. 로그인 상태의 계정 이메일과 로그아웃 버튼이 최상단 탐색 영역에만 표시됩니다.
2. 로그인 상태에서는 사주 콘텐츠 위 계정 상태 카드가 없습니다.
3. 비로그인 안내, 로그인 필수 접근 제한, 시험 모드 Gemini 차단이 유지됩니다.
4. 자동 검사·빌드와 실제 화면의 넓은/좁은 레이아웃을 확인합니다.

## 검증 결과

- 로그인 상태를 모의한 화면 검사에서 이메일과 로그아웃 버튼이 최상단 탐색 영역에 있고 기존 로그인 상태 카드가 없음을 확인했습니다.
- 비로그인·인증 확인 중에는 사주 콘텐츠가 숨겨지고 로그인 안내가 보임을 확인했습니다.
- 자동 검사 36개와 `npm run build`가 통과했습니다. 새 비로그인 브라우저 화면에서도 최상단 브랜드와 로그인 안내만 보였습니다.
- 실제 로그인 계정의 넓은/좁은 화면은 아직 직접 확인하지 못해 `docs/status.md`의 체크를 보류합니다.
