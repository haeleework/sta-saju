# 013-google-account-selection: 재로그인 시 구글 계정 선택

상태: 구현 후 검증 중

작성일: 2026-09-28

## 문제와 목표

서비스에서 로그아웃한 뒤 다시 `Google로 로그인`을 누르면 구글이 앞서 사용한 계정으로 바로 진행할 수 있습니다. 다른 계정을 쓰려는 사람이 계정을 고를 기회를 놓치지 않도록, 로그인 요청마다 구글의 계정 선택 화면을 요청합니다.

## 동작 기준

1. 서비스 로그아웃은 기존처럼 이 브라우저의 Supabase 로그인 세션만 종료합니다. 구글 계정 자체를 로그아웃시키거나 다른 사이트의 로그인 상태를 바꾸지 않습니다.
2. `Google로 로그인`을 누를 때 Supabase의 Google OAuth 요청에 `prompt=select_account`를 전달합니다. 기존 `/auth/callback` 복귀 주소와 로그인 완료 처리 방식은 유지합니다.
3. 구글 계정 선택 화면은 구글이 제공하며, 앱이 계정 목록을 직접 수집하거나 표시하지 않습니다. 사용 가능한 계정이 없으면 구글이 새 계정으로 로그인하는 화면을 표시할 수 있습니다.
4. 계정 선택 취소나 실패 시에는 로그인 전 화면에 남고 기존 오류 안내를 표시합니다. 다른 계정으로 로그인한 뒤 이전 계정의 저장 결과가 보이지 않아야 합니다.

## 확인 방법

- 로그인 요청 옵션의 `prompt` 값과 복귀 주소를 자동 검사합니다.
- 전체 자동 검사와 배포용 빌드를 실행합니다.
- 배포 화면에서 A 계정 로그아웃 → 로그인 버튼 → 계정 선택 화면 → B 계정 로그인 순서를 직접 확인합니다. 실제 구글 계정 선택은 사용자만 할 수 있으며, 직접 확인 전에는 완료로 표시하지 않습니다.

## 검증 결과

- 2026-09-28: 배포 사이트의 기존 로그인 코드에는 `select_account` 요청이 없는 것을 확인했습니다.
- 로그인 옵션 자동 검사, 타입 검사, 전체 자동 검사 75개와 배포용 빌드가 통과했습니다.
- 실제 구글 계정 선택 화면과 서로 다른 두 계정의 결과 격리는 아직 확인하지 않았습니다.
