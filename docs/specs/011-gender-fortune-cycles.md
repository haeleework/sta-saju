# 011-gender-fortune-cycles: 성별 입력과 대운·세운 흐름

상태: 구현 및 자동 검증 완료 (2026-09-23)

작성일: 2026-09-23

## 목표

사용자가 생년월일·출생시간과 함께 대운 방향 계산에 쓸 성별 기준을 입력하면, 코드가 대운(약 10년 단위로 바뀌는 전통 명리의 시간 흐름)과 세운(해마다 바뀌는 흐름)을 계산해 보여줍니다. 계산으로 확인한 간지·기간과 전통 명리 규칙에 따른 해석을 구분하고, 미래를 확정하거나 중요한 결정을 지시하지 않습니다.

## 확정한 계산 기준

아래 기준은 같은 생년월일시에도 대운 방향이나 시작 연도를 바꿀 수 있어 사용자에게 설명한 뒤 2026-09-23에 확정했습니다.

1. **성별과 대운 방향:** `lunar-javascript@1.7.7`의 기본 규칙대로 남성을 `1`, 여성을 `0`으로 전달합니다. 출생연도 천간이 양이면 남성은 순행·여성은 역행, 음이면 남성은 역행·여성은 순행합니다.
2. **첫 대운 시작 시점:** 기본 방식(`sect=1`)을 사용합니다. 순행은 출생 뒤의 다음 절, 역행은 출생 전의 이전 절까지 날짜·시진 차이를 구해 `3일=1년`, `1일=4개월`, `1시진=10일`로 환산합니다. 한국 표준시와 기존 절기 계산 기준을 맞춥니다.
3. **세운 표시 범위:** 현재 연도가 속한 대운과 그 대운에 포함된 세운 전체를 보여줍니다. 분석은 일간과 각 운의 오행 관계(돕는 힘·표현하는 힘·자원을 다루는 힘·규칙과 책임)까지만 보수적으로 설명합니다.

## 결정 뒤 적용할 공통 원칙

- 양력과 한국 표준시, 23시 일자 변경, 진태양시 보정 없음이라는 기존 계산 기준을 유지합니다.
- 대운·세운 계산은 `lib/saju`에서 수행하고 Gemini에게 계산을 맡기지 않습니다.
- 성별 값은 대운 방향 계산에만 사용하며, 성격이나 역할을 성별로 단정하지 않습니다.
- 화면에서 처음 쓰는 용어는 일상적인 뜻과 짧은 예시를 함께 설명합니다.
- 계산된 방향·시작 시점·간지·연도와 전통 규칙에 따른 관계 해석을 시각적으로 구분합니다.
- 새 Gemini 호출은 만들지 않고, 비용이 발생하는 실제 Gemini 호출도 검증에 사용하지 않습니다.
- 기존 저장 결과에는 성별이 없으므로 대운·세운을 임의 생성하지 않습니다. 새 입력이 필요하다는 안내를 표시합니다.

## 예정 입력·화면

- 기존 입력 폼에 대운 방향 계산에 사용할 값을 필수로 받습니다. 최종 라벨과 선택지는 위 기준 결정 뒤 확정합니다.
- 계산 결과 아래에 순행/역행, 첫 대운 시작 시점과 근거를 쉬운 말로 표시합니다.
- 현재 연도가 포함된 대운을 강조하고, 선택된 범위의 대운·세운 간지와 나이를 표시합니다.
- 각 운의 천간·지지 오행이 일간과 어떤 관계인지 짧게 설명하되 좋은 일·나쁜 일의 발생을 예언하지 않습니다.
- 현재 연도가 계산 범위 밖이면 가장 가까운 범위로 조용히 바꾸지 않고 범위 안내를 표시합니다.

## 실패와 개인정보

- 필요한 입력이 없거나 허용된 값이 아니면 계산하지 않고 수정할 항목을 알려줍니다.
- 원본 생년월일시와 성별 입력을 Gemini 요청이나 기존 브라우저 저장 결과에 새로 포함하지 않습니다.
- 라이브러리 결과가 비어 있거나 기간이 맞지 않으면 그럴듯한 값을 만들어 표시하지 않습니다.

## 검증 계획

- 같은 생년월일시에 방향 계산용 입력만 바꿨을 때 순행·역행, 대운 간지와 시작 연도가 달라지는 사례를 검사합니다.
- 양년·음년 각각에서 두 입력값의 방향이 뒤집히는지 검사합니다.
- 첫 대운 시작 시점의 절기 경계 전후 사례와 채택한 환산 방식을 독립된 기대값으로 검사합니다.
- 현재 연도의 대운 선택, 대운 경계 연도, 각 대운의 세운 10개와 나이·간지를 검사합니다.
- 입력 누락·잘못된 값, 기존 저장 결과, 로그인 제한, 기존 사주 계산·해석 API 호출 정책을 회귀 검사합니다.
- `npm run check`, `npm run build`, `git diff --check`를 실행하고 검증 결과를 이 문서에 기록합니다.

## 이번 범위에서 제외

십성 및 글자 관계(합·충·형·해·파)를 반영한 심화 해석은 다른 워크트리에서 구현하므로 이 Spec에서 제외합니다. 용신, 길흉 점수, 사건 예측, 월운·일운, Gemini 추가 호출도 제외합니다.

## 검증 결과

- 독립 테스트에서 양년·음년 각각 남성·여성의 순행·역행 반전, `sect=1`의 첫 대운 오프셋과 시작 시각, 대운 경계 연도, 세운 10개의 연도·간지·세는나이를 확인했습니다.
- 잘못된 성별과 기준 연도는 계산하지 않으며, 화면이 성별을 필수로 받고 대운·세운을 쉬운 말로 설명하는지 확인했습니다.
- Gemini 프롬프트와 브라우저 저장 결과에 성별 및 원본 생년월일시가 새로 포함되지 않음을 확인했습니다. 실제 Gemini 호출은 하지 않았습니다.
- `npm run check`: 형식 검사 및 전체 자동 검사 52개 통과(이 기능의 독립 검사 6개 포함).
- `npm run build`: 배포용 빌드 성공. `git diff --check`: 오류 없음(Windows 줄바꿈 안내만 출력).
