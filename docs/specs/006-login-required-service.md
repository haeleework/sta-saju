# 006-login-required-service: 로그인 후에만 사주 서비스 이용

> 아래 브라우저 저장 결과 안내는 초기 설계 기록입니다. 현재 사주 결과의 저장·재열람 정책은 `016-account-only-reading-storage.md`를 따릅니다.

상태: 코드·자동 검사 완료 · 실제 구글 계정 확인 전

작성일: 2026-09-23

## 정책

정식 서비스와 비용 없는 로그인 시험 모드 모두 구글 로그인 확인 전에는 사주 입력·계산·AI 해석·이 브라우저의 기존 저장 목록을 보여주거나 이용할 수 없습니다. 기존의 “계정 저장할 때만 로그인” 결정을 대체합니다. 로그인 이후에는 현재 구현된 사주 흐름을 이용합니다. 계정별 데이터베이스 저장은 `004`의 별도 단계입니다.

## 화면·서버 동작

- 인증 상태를 확인하는 동안 사주 화면을 렌더하지 않고 대기 문구를 보여줍니다. 비로그인이면 구글 로그인 버튼만 보여줍니다.
- 로그인 성공을 확인한 뒤 사주 입력과 기존 브라우저 저장 결과를 표시합니다. 로그아웃 또는 세션 만료 시 즉시 사주 화면과 화면상의 결과를 숨깁니다.
- `/api/reading`은 매 요청마다 서버에서 사용자 인증을 검증합니다. 비로그인 요청에는 `401`을 반환하고 Gemini를 호출하지 않습니다.
- `AUTH_TEST_MODE=true`는 로그인 후에도 Gemini 호출을 막습니다. 계산 및 기존 로컬 결과 열람은 로그인 후 가능합니다.
- 기존 `localStorage` 결과는 현재 브라우저에 남아 있습니다. 로그인한 사람이라도 같은 브라우저의 이전 결과가 보일 수 있으므로 계정별 비공개 저장으로 오인시키지 않습니다. 공용 기기에서는 브라우저 자료 삭제가 필요합니다.

## 완료 조건

1. 비로그인·인증 확인 중에는 사주 입력과 저장 목록이 DOM에 나타나지 않습니다.
2. 인증 성공 후에만 사주 입력이 나타나고, 로그아웃하면 사라집니다.
3. 비로그인 API 요청은 401이며 Gemini 호출이 0회입니다.
4. 시험 모드의 로그인 이후에도 Gemini 요청은 차단됩니다. 일반 모드에서는 인증된 요청의 기존 기능이 유지됩니다.
5. 실제 구글 로그인·로그아웃과 새로고침 후 상태를 참가자가 확인합니다.

## 검증 결과

- 비로그인 `http://localhost:3000/` 응답에 사주 입력과 저장 목록이 없음을 확인했습니다.
- 비로그인 `/api/reading` 직접 요청은 401을 반환했습니다.
- 자동 검사에서 비로그인 기본·주제 요청의 Gemini 호출 0회, 로그인 상태 모의 요청의 기존 해석 동작, 시험 모드의 503 차단을 확인했습니다.
- `npm run check` 형식 검사 및 자동 검사 32개 통과, `npm run build` 성공.
- 실제 구글 계정 로그인·로그아웃·새로고침 후 화면 전환은 아직 참가자 확인 전입니다. 따라서 `docs/status.md`의 체크는 보류합니다.
