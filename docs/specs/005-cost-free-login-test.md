# 005-cost-free-login-test: Gemini 비용 없는 구글 로그인 시험

상태: 구현됨 · 실제 구글 계정 로그인 확인 전

작성일: 2026-09-23

## 목표

구글 로그인 기능을 실제로 시험하는 동안 Gemini 요청을 발생시키지 않아 LLM 사용 비용을 막습니다. 이번 시험은 로그인·로그아웃 상태 확인에 집중하며, 계정별 해석 결과 저장은 `004-account-reading-storage.md`의 별도 구현으로 남깁니다.

## 동작

- 로컬 설정 `AUTH_TEST_MODE=true`일 때 화면에 `구글 로그인 시험` 영역을 보여줍니다. 방문자는 사주 입력 없이도 구글 로그인 버튼을 누를 수 있습니다.
- 구글 로그인 성공 후 앱으로 돌아오면 로그인 상태와 계정 이메일을 보여주고 로그아웃할 수 있습니다. 로그인 취소·실패도 안내합니다. 실제 구글 계정 선택과 동의는 참가자가 직접 합니다.
- 시험 모드에서도 로그인 확인 전에는 사주 화면을 볼 수 없습니다. 로그인 후 기존 계산 기능을 유지하되 `해석 만들기`와 새로운 관심 주제 해석 생성을 비활성화하고 이유를 표시합니다. 서버의 `/api/reading`은 비로그인을 거절하고, 로그인 상태에서도 Gemini 호출 전에 시험 모드를 검사해 요청을 거절합니다.
- 로그인 후 기존 브라우저 저장 결과는 조회할 수 있지만 새 AI 해석은 만들지 않습니다. 데이터베이스 결과 저장·읽기·삭제는 이 시험에 포함하지 않습니다.
- 시험 모드가 꺼지면 기존 Gemini 해석 동작이 돌아옵니다. `AUTH_TEST_MODE`는 서버 설정이며 공개 키·토큰·Google 비밀값과 무관합니다.

## 완료 조건

1. 시험 모드에서 구글 로그인 화면으로 이동하고 성공·실패·로그아웃 상태를 표시합니다. 로그인 상태는 새로고침 뒤에도 올바르게 복원됩니다.
2. 시험 모드에서 UI 버튼과 `/api/reading` 직접 요청 모두 Gemini를 호출하지 않습니다. 자동 검사는 외부 호출이 0회임을 확인합니다.
3. 시험 모드를 끄면 기존 해석 API와 화면이 다시 작동합니다. 기존 사주 계산·저장 결과 읽기를 손상시키지 않습니다.
4. 구글 제공자 또는 허용된 복귀 주소 설정이 없으면 무엇이 필요한지 안내하되, 성공했다고 표시하지 않습니다.

## 구현 전 확인

- Supabase 프로젝트 URL·publishable key는 로컬 `.env`에 설정돼 있습니다. Google 제공자 활성화와 앱 콜백 허용 목록은 실제 로그인 시험에서 확인합니다.
- 이 시험 모드는 개발 환경용입니다. 공개 배포에는 켜지 않으며, 해석 기능을 끄는 운영 기능으로 간주하지 않습니다.

## 검증 결과

- 시험 모드 화면에서 `Google로 로그인` 버튼과 Gemini 차단 안내를 확인했습니다.
- 자동 검사에서 시험 모드의 Gemini 호출 0회, 인증 콜백의 내부 복귀 주소를 확인했습니다.
- `npm run check` 및 `npm run build`를 통과했습니다.
- 실제 구글 계정 선택·로그인 완료·로그아웃은 참가자의 화면 확인이 필요합니다. 완료 전까지 `docs/status.md`의 체크는 보류합니다.
