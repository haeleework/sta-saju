# 012-integrated-reading-and-account-storage: 세 기능 통합 동작

> 2026-09-29부터 브라우저 저장은 제거되었습니다. 이 문서의 관련 과거 문구보다 `016-account-only-reading-storage.md`의 계정 단일 저장 정책을 우선합니다.

상태: 코드 통합 및 자동 검증 완료 · 실제 계정 간 접근 격리 검증 전

작성일: 2026-09-28

## 목표

별도 워크트리에서 만든 십성·합충 심화 해석(`010`), 성별 기준 대운·세운(`011`), 계정별 결과 저장(`004`)이 한 서비스 화면에서 서로의 결과를 지우거나 잘못 저장하지 않고 동작해야 합니다. 처음 사주를 보는 사람에게는 계산된 사실과 전통 규칙에 따른 풀이를 쉬운 한국어로 구분해 보여줍니다.

## 통합 사용자 흐름

1. 구글 로그인 전에는 사주 입력·계산·해석·계정 결과를 볼 수 없습니다.
2. 로그인 후 양력 생년월일·출생시간·대운 방향 계산에 쓸 성별을 입력하면 8글자 구성, 오행 그래프, 십성·글자 관계, 대운·세운을 표시합니다. 성별은 대운 방향에만 쓰고 성격 판단에 사용하지 않습니다.
3. 십성·합충은 `010`의 제한된 관계만 계산합니다. 대운·세운은 `011`의 `sect=1` 기준과 일간 중심의 기본 오행 관계만 사용합니다. 두 결과를 억지로 합쳐 길흉이나 사건을 예언하지 않습니다.
4. 기본·주제별 Gemini 해석은 기존 버튼으로만 생성합니다. 두 계산 기능을 추가했다는 이유로 Gemini 호출을 늘리지 않습니다.
5. 현재 해석 결과가 있을 때만 사용자가 `계정에 저장`을 눌러 저장합니다. 과거 브라우저 목록은 자동 업로드하지 않습니다. 계정 결과를 다시 열면 저장된 구성·해석과 구성에서 다시 계산할 수 있는 심화 해석을 보여줍니다. 성별을 저장하지 않으므로 대운·세운은 임의 복원하지 않고 새 입력을 안내합니다.
6. 저장 결과를 열어 같은 생년월일시와 성별을 다시 입력하면 기존 해석 결과를 유지하고 대운·세운을 계산합니다. 다른 사주 구성으로 입력하면 기존 현재 결과와 주제 선택을 해제해 서로 다른 사람의 결과가 섞이지 않게 합니다.

## 개인정보와 실패 처리

- 원본 생년월일시·성별을 기존 Gemini 요청, 브라우저 저장 형식, 계정 결과 테이블에 새로 추가하지 않습니다. 사주 구성과 해석도 계정과 연결되므로 비공개로 취급합니다.
- 잘못된 입력이나 운 계산 실패 시 가짜 결과를 표시하지 않습니다. 저장 실패 시 저장 성공으로 표시하지 않고, 기존 브라우저 결과를 삭제하지 않습니다.
- `public.saju_readings`의 실제 사용자별 행 접근 제한은 `004`의 완료 조건입니다. 운영 DB 구조·정책 확인만으로 완료로 간주하지 않습니다.

## 통합 검증 기준

- 세 기능이 함께 있는 상태에서 `npm run check`, `npm run build`, `git diff --check`를 통과합니다.
- 같은 사주를 다시 입력했을 때 계정에서 열어 둔 해석을 유지하고 대운·세운을 계산하는 회귀 검사를 합니다. 다른 사주를 입력하면 기존 해석을 해제합니다.
- 로그인 제한, 기존 해석 생성·브라우저 저장·계정 저장의 회귀 검사를 합니다. 실제 Gemini 호출은 비용을 발생시키므로 자동 검증에서 제외합니다.
- 실제 구글 계정 A·B로 서로의 저장 결과를 조회·갱신·삭제할 수 없는지 확인해야 `004`와 이 통합 Spec을 완료 처리합니다.

## 이번 범위에서 제외

삼합·방합·형·해·파 등 추가 관계, 용신·길흉 점수·구체적 사건 예측, 과거 브라우저 결과 일괄 이전, 원본 생년월일시와 성별의 계정 저장, 추가 Gemini 호출은 제외합니다.

## 검증 결과

- 구현을 맡지 않은 독립 테스트 담당이 `tests/integrated-reading.test.ts`에 회귀 검사 6개를 추가했습니다. 계정 결과 재열람, 같은 구성의 해석 유지·운 재계산, 다른 구성의 해석 해제, 브라우저·계정 저장 분리, 운 초기화 및 Gemini 추가 호출 방지를 확인했습니다.
- `npm run check`: 형식 검사와 전체 자동 검사 74개 통과. `npm run build`: 성공. `git diff --check`: 오류 없음.
- 실제 Gemini 호출, 실제 Supabase 데이터 변경, 브라우저 화면 조작은 하지 않았습니다.
- 실제 Google 계정 A·B 접근 격리: 미실시. 따라서 `docs/status.md`의 `004`와 이 통합 Spec은 미완료로 둡니다.
